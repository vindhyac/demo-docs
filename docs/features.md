# Demo App features

Reference documentation for Demo App, a fictional workflow tool used in the n8n portfolio. The launch pipeline (workflow 7) adds a new section to this page whenever a project ships.

## Data tables

Store rows of structured data inside Demo App without an external spreadsheet.

- Create a table with text, number, date and boolean columns.
- Add, edit and delete rows from the table view or from any workflow.
- Filter and sort the table view by any column.

**Limits:** viewing and copying from the table view works best under 500 rows.

## Slack notifications

Send a message to any Slack channel when something happens in a workflow.

- Choose the channel and write the message, using fields from earlier steps.
- Add Approve and Decline buttons to pause a workflow until someone responds.

## Scheduled runs

Run any workflow on a schedule: every few minutes, hourly, daily or weekly.

- Times use your workspace time zone.
- Pause a schedule at any time without deleting the workflow.
